About This Site

This site is my Lab 04 assignment for CSIT 121. The theme is my three favorite soccer players, and each one gets his own page with a photo of him. The point of the lab is to compare web graphic formats, so I saved each photo in a different one and wrote about why that format fits that particular image.

Every photo is freely licensed from Wikimedia Commons, and I credited the photographer and the license underneath each image and again on the player's page.

Comparing the Three Formats

All three photos were resized to the same width of 900 pixels before I saved them, so the file sizes below are a fair comparison. The difference between them is only the format:

  • ronaldo.jpg — 97 KB
  • mbappe.png — 867 KB
  • debruyne.webp — 73 KB

The PNG is almost nine times bigger than the JPG even though both look about the same on screen. That surprised me at first, but it makes sense once you know PNG is lossless and keeps every single pixel exactly as it was. WebP came out the smallest of all three, which is why so many sites use it now.

About the Background

The striped grass background on every page is an SVG pattern I made myself for this lab, so there is no outside source to credit for it. I used two shades of green to imitate the mown stripes you see on a real pitch, and I put the text on a white panel so it stays easy to read.
