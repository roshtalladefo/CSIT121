About This Site

This is my Lab 04 assignment for CSIT 121. The theme is my three favorite soccer players, and each one gets a page with a photo of him saved in a different web graphic format. Every photo is freely licensed from Wikimedia Commons and credited to the photographer.

  • Cristiano Ronaldo — .jpg
  • Kylian Mbappé — .png
  • Kevin De Bruyne — .webp

Comparing the Three Formats

All three photos were resized to the same 900 pixel width before saving, so the only difference between these file sizes is the format:

  • ronaldo.jpg — 97 KB
  • mbappe.png — 867 KB
  • debruyne.webp — 73 KB

The PNG is almost nine times bigger than the JPG even though they look the same on screen, because PNG is lossless and keeps every pixel. WebP came out smallest of all three, which is why so many sites use it now.

About the Background

The striped grass background is an SVG pattern I made myself for this lab, so there is no outside source to credit. The text sits on a white panel so it stays easy to read.
