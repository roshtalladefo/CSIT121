About the WebP Format

WebP is a newer format developed by Google specifically for the web. The interesting thing about it is that it does not make you choose between the strengths of JPG and PNG, because it can do both.

Key Traits

  • Colors: up to about 16.7 million
  • Compression: both, since WebP can be saved as lossy like a JPG or lossless like a PNG
  • Transparency: supported, and it works in lossy mode too, which PNG cannot do
  • Animation: supported, so it can replace an animated GIF as well

Why WebP Suits This Image

This is the clearest example on the site of why WebP matters. It is the biggest image here by pixel count, since it is square rather than rectangular, and it is still the smallest file at 73 KB. That is smaller than the JPG and about twelve times smaller than the PNG, with no difference I can see on screen.

The one catch is support. WebP works in every current browser, but a very old one might not open it, which is the main reason people still fall back to JPG.
